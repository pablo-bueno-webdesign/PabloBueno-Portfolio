# Pablo Bueno — Portfolio

Portfolio web de Pablo Bueno, diseñador digital y web. Presenta proyectos, servicios, referencias visuales, experiencia y vías de contacto.

## Contenido

- **Proyectos:** Music Wave Mag, Real Federación Española de Rugby y el videoclip «Dónde Estás».
- **Servicios:** diseño web y diseño gráfico digital.
- **Inspiración:** selección de proyectos, estudios y artistas.
- **Sobre mí:** perfil, experiencia, formación y habilidades.
- **Contacto:** correo, redes sociales y formulario visual.

## Tecnologías

Sitio estático construido con HTML y CSS, sin dependencias ni proceso de compilación. Los estilos están separados entre un reset y la hoja principal. Las imágenes, vídeos, fuentes e iconos se sirven desde `assets/`.
